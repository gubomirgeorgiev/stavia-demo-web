My documents

What it is

Every document the server has issued you for your bookings: confirmations, payment and refund documents, invoices and credit notes, complaints received. Each opens as a PDF. The screen is for the Test environment: in the demo on the device there is no server and the list is empty.

Where

In the Test environment: Menu → My documents. In the demo on the device the menu has “Invoices” in this place.

On the screen

The picture shows sample data, as in the Test environment.

  1. All — every document, newest first, by month. Beside it are Invoices (only invoices and credit notes) and Payments (payment and refund documents).
  2. Bookings — booking confirmations and complaints received.
  3. Invoice — each document is a line: its kind (“Booking confirmation”, “Payment document”, “Refund document”, “Invoice”, “Credit note”, “Complaint received”), the place, “No. …” and the date, with the amount on the right. Tap the line to see the PDF; from there you print, save or share it.
  4. Check a document — under the list: opens the check, where a document’s code tells you whether the server issued it and whether it still holds.
  5. Issued by the server of the test environment… — the documents are samples, not tax documents; each has a code anyone can check it by.

Until you have a booking in the Test environment, and always in the demo on the device, the list says “No documents yet. Each booking and payment brings its documents here.”

Settings and options

  • Filter: “All”, “Invoices”, “Payments” or “Bookings”.
  • Refresh: pull the list down.

States

  • Loading: grey lines where the documents will be.
  • Empty: “No documents yet. Each booking and payment brings its documents here.” With a filter: “None of this kind yet.”
  • Error: “This did not load” — “Nothing was lost. Try again in a moment.” and “Try again”.

Questions

Are the invoices real? No. The server of the test environment issues them; no real money moves and the documents are not tax documents.

How does someone check a document of mine? Every PDF has a QR code and a check code. The “Check a document” page says whether the server issued it and whether it is still valid.

Why is “My documents” missing from the menu in the demo? The server issues the documents. On a device without a server the sample invoices are under “Invoices”.
