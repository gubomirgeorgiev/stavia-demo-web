Check a document

What it is

Checking whether a document from Stavia is genuine and valid: a booking confirmation, a payment or refund document, an invoice, a credit note and the others. The answer comes from Stavia’s records, not from the file, so an edited file does not pass.

Where

In the Sandbox environment the QR code at the foot of a document leads here, in the web version of the app, with the id and code filled in. Documents from the Test environment say “Check it in the Stavia apps → Check a document”: in the driver app, the “Check a document” button under the list in “My documents”; in Stavia Business and in the console, the line with your name at the top → “Check a document”. In the demo on the device no documents are issued and these buttons are not there.

On the screen

  1. A document’s id and code are at its foot, under the QR code. … — where to find them and where the answer comes from.
  2. Document id — the id from the document. You can also paste the QR code’s whole text here (“STAVIA-DOC …”): on “Check” the id and code fill in by themselves.
  3. Code — the check code from the document.
  4. Check — asks Stavia’s records.

The answer is under the button: “Issued through Stavia and valid” or “Cancelled”, the kind of document, “No. … · …” (number and date), “Issued by …”, “Amount …” and “Fingerprint (SHA-256): …”, to compare with the file. Documents from test data carry “TEST” and “TEST: a sample made from test data; not a tax document.”

Settings and options

No settings here.

States

  • No such document: “No document has this id and code.”
  • The check did not answer: “The check did not answer. Try again in a minute.”
  • Checking: a spinner under the button.
  • In the demo on the device Stavia issues no documents, so every check answers “No document has this id and code.” Documents exist in the test environments.

Questions

Where are the id and the code? At the foot of the document, under the QR code.

The document is valid, but the amount is different. Trust the answer here: it comes from Stavia’s records. Compare the fingerprint with the file too.

Can I paste the QR code’s text? Yes: paste it into “Document id” and tap “Check”; the id and code are split by themselves.
