My code

What it is

One code for every entrance with staff: with a booking or without one, on the way in and on the way out. The code goes with your car’s plate. Without a booking nothing starts before you confirm on your phone.

Where

On the map: the My code button above the list. Or Menu → My code. While it is open, the screen is brighter, so the code scans more easily.

On the screen

  1. Show it at the entrance. You confirm on your phone before anything starts. — above this line are the QR code, a coral line under it (the code is live, not a picture) and your plate. Once a place has confirmed you in, until you leave, the line is “You are parked at …. Show the code at the exit too.”
  2. Changes every 15 seconds, so a photo of it does not work. — the code changes by itself; show it from the app.
  3. A test code: test places only, no real parking. — with the “TEST” tag.

When staff scan your code at an entrance without a booking, “Coming in with your code” opens on your phone: “The staff at the entrance scanned your code. Confirm to start your stay; if it was not you, say no.” “Start · pay when you leave” starts a Park now, pay when you leave stay, and “Not me” (or the cross) says no. The sheet does not close any other way.

Settings and options

No settings here. The code is the same for every place; the car is the one chosen in your profile.

States

  • No car: “Add your car first: the code goes with its plate.” → “Add a car”.
  • The code did not load: “The code did not load. Check the connection and try again.” → “Try again”.
  • Loading: a spinner where the code goes.
  • Staff in Stavia Business (“Entry”) scan the code. In the demo on the device, the staff and the driver are on the same device; in the Test environment the staff scan from their own phone. Nothing opens a barrier.

Questions

Do I need a booking? No, if the place takes the code (in the samples, “TEST Hilton Sofia”, with staff at the entrance). The staff scan, you confirm, and a stay paid when you leave begins.

Can I send someone a photo of the code? No: the code changes every 15 seconds and the photo stops working.

How is it different from the code in a booking? A booking’s code is for that booking only. “My code” is yours: for places with staff, with or without a booking.
