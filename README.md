# Stavia demo (web)

The web app of the Stavia demo, for testing on any device:
**https://gubomirgeorgiev.github.io/stavia-demo-web/**

- Sample data only. Payments are simulated: no money moves and no card is charged. No real places, people or number plates.
- Each device signs in anonymously to one shared demo server. Other testers see what you do, and the demo can be reset at any time.
- This repository holds only the built app. The source code is private.

---

Уеб приложението на демото Stavia, за тестване от всяко устройство. Само примерни данни и симулирани плащания. Всички устройства споделят един демо сървър: другите тестващи виждат какво правиш, а демото може да бъде нулирано по всяко време.
