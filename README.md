# Stavia demo (web)

The web apps of the Stavia demo, for testing on any device:

- **Stavia Demo**, everything in one: https://gubomirgeorgiev.github.io/stavia-demo-web/
- **Stavia Business**, for hosts and their staff: https://gubomirgeorgiev.github.io/stavia-demo-web/business/
- **Support console**, for Stavia's own team: https://gubomirgeorgiev.github.io/stavia-demo-web/console/

- Sample data only. Payments are simulated: no money moves and no card is charged. No real places, people or number plates.
- Each device signs in anonymously to one shared demo server. Other testers see what you do, and the demo can be reset at any time.
- This repository holds only the built apps. The source code is private.

---

Уеб приложенията на демото Stavia, за тестване от всяко устройство: демото „всичко в едно“, Stavia Business (/business/) и конзолата на поддръжката (/console/). Само примерни данни и симулирани плащания. Всички устройства споделят един демо сървър: другите тестващи виждат какво правиш, а демото може да бъде нулирано по всяко време.
